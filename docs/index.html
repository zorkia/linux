เครื่อง Windows หรือ macOS ใช้เป็น host สำหรับเปิด Docker เท่านั้น ส่วนคำสั่ง Linux ในแต่ละ LAB ให้รันภายใน Container rpi-lab

เรื่อง Network ของ Docker

Docker Container มี IP ของตัวเอง ซึ่งไม่ใช่ IP ของ Windows/macOS host และไม่ใช่ IP ของ Raspberry Pi จริง การเข้า Web, Node-RED หรือ MQTT จากนอก Container ต้องอาศัย Docker Port Mapping ที่กำหนดตั้งแต่ตอนสร้าง Container ใน LAB 01
