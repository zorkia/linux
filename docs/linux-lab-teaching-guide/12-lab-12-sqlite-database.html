Mini Project: IoT Device Status Log

ตัวอย่างนี้ทำระบบรับข้อมูลจากฟอร์มบนเว็บ แล้วบันทึกลง SQLite จากนั้นหน้าเว็บจะดึงข้อมูลล่าสุดมาแสดงในตารางทุก 2 วินาที

ข้อมูลที่เก็บ:

Field ความหมาย
id ลำดับรายการ
created_at เวลาที่บันทึก
device_id รหัสอุปกรณ์ เช่น ESP32-001
location ตำแหน่งอุปกรณ์ เช่น Lab Room
temperature อุณหภูมิ
humidity ความชื้น
status สถานะ เช่น NORMAL, WARNING, OFFLINE
note หมายเหตุสั้น ๆ

1. สร้าง Python API

mkdir -p ~/iot-web
nano ~/iot-web/app.py

ใส่:

from http.server import BaseHTTPRequestHandler, HTTPServer
from pathlib import Path
import json
import sqlite3

DB_PATH = Path.home() / "iot-data" / "device_status.db"


def get_db():
    DB_PATH.parent.mkdir(parents=True, exist_ok=True)
    con = sqlite3.connect(DB_PATH)
    con.row_factory = sqlite3.Row
    return con


def init_db():
    with get_db() as con:
        con.execute("""
            CREATE TABLE IF NOT EXISTS device_logs (
                id INTEGER PRIMARY KEY AUTOINCREMENT,
                created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
                device_id TEXT NOT NULL,
                location TEXT NOT NULL,
                temperature REAL NOT NULL,
                humidity REAL NOT NULL,
                status TEXT NOT NULL,
                note TEXT
            )
        """)


class Handler(BaseHTTPRequestHandler):
    def send_json(self, data, status=200):
        body = json.dumps(data).encode("utf-8")
        self.send_response(status)
        self.send_header("Content-Type", "application/json")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_GET(self):
        if self.path != "/api/logs":
            self.send_json({"error": "not found"}, 404)
            return
        with get_db() as con:
            rows = con.execute("""
                SELECT id, created_at, device_id, location,
                       temperature, humidity, status, note
                FROM device_logs
                ORDER BY id DESC
                LIMIT 20
            """).fetchall()
        self.send_json([dict(row) for row in rows])

    def do_POST(self):
        if self.path != "/api/logs":
            self.send_json({"error": "not found"}, 404)
            return

        length = int(self.headers.get("Content-Length", "0"))
        data = json.loads(self.rfile.read(length).decode("utf-8"))

        with get_db() as con:
            con.execute("""
                INSERT INTO device_logs
                    (device_id, location, temperature, humidity, status, note)
                VALUES (?, ?, ?, ?, ?, ?)
            """, (
                data["device_id"],
                data["location"],
                float(data["temperature"]),
                float(data["humidity"]),
                data["status"],
                data.get("note", "")
            ))

        self.send_json({"ok": True}, 201)


init_db()
HTTPServer(("127.0.0.1", 5000), Handler).serve_forever()

3. ตั้งค่า Nginx Proxy

ขั้นตอนนี้ทำให้หน้าเว็บและ API ใช้ address เดียวกันผ่าน Nginx:

http://localhost:8080/status.html
http://localhost:8080/api/logs

ผู้ใช้ไม่ต้องเรียก Python API ที่ port 5000 โดยตรง เพราะ Nginx จะรับ /api/ แล้วส่งต่อไปที่ 127.0.0.1:5000 ภายใน Container ให้เอง

แก้ default site:

sudo nano /etc/nginx/sites-enabled/default

ใช้ configuration นี้:

server {
    listen 80 default_server;
    listen [::]:80 default_server;

    root /var/www/html;
    index status.html index.html;

    location / {
        try_files $uri $uri/ =404;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:5000/api/;
        proxy_set_header Host $host;
    }
}

ตรวจและ reload:

sudo nginx -t
sudo nginx -s reload
curl http://127.0.0.1/api/logs

เปิดจาก Browser บน Windows/macOS:

http://localhost:8080/status.html

แบบฝึกหัด

เพิ่มอย่างน้อย 10 records จาก ESP32-01 และ ESP32-02 แล้วหา COUNT, AVG(temp), MAX(temp), MIN(humi) และจำนวนข้อมูลแยกตาม device

  1. อุปกรณ์ใดมีอุณหภูมิเฉลี่ยสูงที่สุด
  2. มีรายการใดเป็น WARNING หรือ OFFLINE บ้าง
  3. ถ้าจะนำระบบนี้ไปใช้จริง ควรเพิ่ม field อะไรอีก
