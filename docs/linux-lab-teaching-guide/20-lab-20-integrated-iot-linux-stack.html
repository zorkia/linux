เมื่อสร้าง Container ตาม LAB 01 แล้ว การเข้าจาก Windows/macOS host จะเป็น:

Host port        Container service
8080       --->  Nginx :80
1880       --->  Node-RED :1880
1883       --->  Mosquitto :1883

เครื่องอื่นใน LAN ต้องใช้ IP ของ Windows/macOS host ไม่ใช่ IP ภายใน Container

Start Container

docker start -ai rpi-lab
su - piuser

Start Services

pgrep mosquitto || sudo mosquitto -c /etc/mosquitto/mosquitto.conf -d
pgrep nginx || sudo nginx
pgrep -af node-red || nohup node-red > ~/node-red.log 2>&1 &
pgrep -af "python3 app.py" || nohup python3 ~/iot-web/app.py > ~/iot-web/api.log 2>&1 &

ตรวจ:

ss -tuln

ควรพบ:

80    Nginx
5000  Python API
1880  Node-RED
1883  Mosquitto

ตรวจ Port Mapping จาก Windows/macOS host:

docker port rpi-lab

ควรพบ:

80/tcp -> 0.0.0.0:8080
1880/tcp -> 0.0.0.0:1880
1883/tcp -> 0.0.0.0:1883

Start Collector

cd ~/python-lab
source venv/bin/activate
python mqtt_to_sqlite.py

Start Sensor Simulator

เปิด Terminal Windows อีกหน้าต่าง:

docker exec -it rpi-lab bash
su - piuser
cd ~/python-lab
source venv/bin/activate
python mqtt_publisher.py

ตรวจ MQTT

อีก Terminal:

mosquitto_sub -h 127.0.0.1 -t "pkru/iot/+/data" -v

ตรวจ SQLite

sqlite3 ~/iot-data/device_status.db "SELECT * FROM device_logs ORDER BY id DESC LIMIT 10;"

ตรวจ Web Services

จากภายใน Container:

curl http://127.0.0.1
curl http://127.0.0.1/api/logs
curl -I http://127.0.0.1:1880

จาก Browser บน Windows/macOS:

http://localhost:8080
http://localhost:8080/status.html
http://localhost:1880

จากเครื่องอื่นใน LAN:

http://IP-WINDOWS:8080
http://IP-WINDOWS:1880

สำหรับ MQTT client ที่อยู่นอก Container:

Broker: IP-WINDOWS
Port: 1883

SQL Statistics

sqlite3 ~/iot-data/device_status.db
.headers on
.mode column
SELECT COUNT(*) AS records FROM device_logs;
SELECT AVG(temperature) AS avg_temp FROM device_logs;
SELECT MIN(temperature), MAX(temperature) FROM device_logs;
SELECT status, COUNT(*) FROM device_logs GROUP BY status;
SELECT device_id, COUNT(*) FROM device_logs GROUP BY device_id;
.quit

Mini Project

กำหนด:

device_id = รหัสนักศึกษา
topic = pkru/iot/{student_id}/data

ระบบต้อง:

  1. สุ่ม temperature และ humidity ทุก 3 วินาที
  2. Publish MQTT JSON
  3. Node-RED รับได้
  4. Python Collector รับได้
  5. SQLite บันทึกลง device_logs ได้
  6. หน้าเว็บ http://localhost:8080/status.html แสดงข้อมูลจาก SQLite ได้
  7. กรอกข้อมูลผ่าน web form ได้
  8. Query สถิติได้
  9. Nginx ทำงานและ proxy /api/ ไป Python API ได้
  10. Node-RED เปิดจาก http://localhost:1880 ได้
  11. อธิบาย Process, Port และ Docker Port Mapping ได้
