LAB 19 - Node-RED HTTP Dashboard

ก่อนหน้า: LAB 18 - Node-RED and MQTTกลับหน้าแรกถัดไป: LAB 20 - Integrated IoT Linux Stack

วัตถุประสงค์

สร้าง Web/API Endpoint จาก Node-RED โดยไม่ผูกกับ Dashboard package รุ่นใดรุ่นหนึ่ง

เตรียม

docker start -ai rpi-lab
su - piuser
pgrep -af node-red || nohup node-red > ~/node-red.log 2>&1 &

HTTP API

สร้าง Flow:

http in → function → http response

HTTP In:

GET /api/status

Function:

msg.headers = {"content-type":"application/json"};
msg.payload = {
    status: "OK",
    gateway: "raspberrypi"
};
return msg;

ทดสอบ:

curl http://127.0.0.1:1880/api/status

ทดสอบจาก Browser บน Windows/macOS:

http://localhost:1880/api/status

ถ้าเครื่องอื่นอยู่ใน LAN เดียวกัน:

http://IP-WINDOWS:1880/api/status

HTML

สร้าง:

http in → template → http response

URL:

/

Template:

<!DOCTYPE html>
<html>
<head><meta charset="UTF-8"><title>IoT Gateway</title></head>
<body>
<h1>IoT Gateway Dashboard</h1>
<p>Node-RED is running.</p>
</body>
</html>

ทดสอบ:

curl http://127.0.0.1:1880/

จาก Browser บน Windows/macOS:

http://localhost:1880/

แบบฝึกหัด

สร้าง /api/device คืน JSON ที่มี device_id, temp, humi, light, status
