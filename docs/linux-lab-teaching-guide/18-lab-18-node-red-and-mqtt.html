วัตถุประสงค์

เชื่อม Node-RED กับ Mosquitto เพื่อรับและประมวลผลข้อมูล IoT

เตรียม

ถ้า Node-RED จาก LAB 17 ยังทำงานอยู่ ไม่ต้องเริ่มซ้ำ ทบทวน LAB 17 - Start และ LAB 05 - nohup

docker start -ai rpi-lab
su - piuser
pgrep mosquitto || sudo mosquitto -c /etc/mosquitto/mosquitto.conf -d
if ! pgrep -f node-red > /dev/null; then
    nohup node-red >> ~/node-red.log 2>&1 < /dev/null &
    node_red_pid=$!
    printf '%s\n' "$node_red_pid" > ~/node-red.pid
fi

Architecture

Python Sensor → MQTT → Mosquitto → Node-RED

ทุกบริการใน LAB นี้ทำงานอยู่ใน Container เดียวกัน ดังนั้น Node-RED ที่อยู่ใน Container ให้ตั้ง MQTT Broker เป็น 127.0.0.1:1883

ถ้า MQTT client อยู่นอก Container เช่น Windows หรือเครื่องอื่นใน LAN ให้ใช้ localhost:1883 หรือ IP-WINDOWS:1883 ตาม Port Mapping ของ Docker แทน

Broker ใน Node-RED:

Server:

127.0.0.1

Port:

1883

Topic ของ MQTT In:

pkru/iot/+/data

เปิด Node-RED Editor จาก Browser บน Windows/macOS:

http://localhost:1880

สร้าง Flow:

mqtt in → json → function → debug

Function:

const temp = Number(msg.payload.temperature);
msg.payload = {
    device_id: msg.payload.device_id,
    location: msg.payload.location,
    temperature: temp,
    humidity: Number(msg.payload.humidity),
    status: temp > 35 ? "WARNING" : "NORMAL",
    note: "checked by Node-RED"
};
return msg;

ทดสอบ:

mosquitto_pub -h 127.0.0.1 \
  -t "pkru/iot/001/data" \
  -m '{"device_id":"ESP32-001","location":"Lab Room","temperature":36.5,"humidity":70.2,"status":"NORMAL","note":"node-red test"}'

แบบฝึกหัด

รับ pkru/iot/+/data, Parse JSON และสร้างสถานะ WARNING เมื่อ temperature > 35 มิฉะนั้น NORMAL
