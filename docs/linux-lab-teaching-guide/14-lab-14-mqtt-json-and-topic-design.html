LAB 14 - MQTT JSON and Topic Design

ก่อนหน้า: LAB 13 - Mosquitto MQTT Brokerกลับหน้าแรกถัดไป: LAB 15 - Python MQTT Publisher
เครื่องมือสำหรับ LAB นี้

ใช้ mosquitto, mosquitto-clients จาก LAB 13 และ procps สำหรับ pgrep ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

ออกแบบ MQTT Topic และ Payload แบบ JSON สำหรับหลายอุปกรณ์

เตรียม Broker

docker start -ai rpi-lab
su - piuser
pgrep mosquitto || sudo mosquitto -c /etc/mosquitto/mosquitto.conf -d

JSON Payload

Subscriber:

mosquitto_sub -h 127.0.0.1 -t "pkru/iot/001/data" -v

Publisher:

mosquitto_pub -h 127.0.0.1 \
  -t "pkru/iot/001/data" \
  -m '{"device_id":"ESP32-001","location":"Lab Room","temperature":30.5,"humidity":70.2,"status":"NORMAL","note":"topic design test"}'

Payload ชุดนี้ตั้งใจให้ตรงกับตาราง device_logs จาก LAB 12 เพื่อให้ข้อมูลจาก MQTT สามารถบันทึกลง SQLite และแสดงบนเว็บเดียวกันได้

Multi-device

อุปกรณ์ 001:

pkru/iot/001/data

อุปกรณ์ 002:

pkru/iot/002/data

อุปกรณ์ 003:

pkru/iot/003/data

รับทั้งหมด:

mosquitto_sub -h 127.0.0.1 -t "pkru/iot/+/data" -v

Status / Command

mosquitto_pub -h 127.0.0.1 -t "pkru/iot/001/status" -m "ONLINE"
mosquitto_sub -h 127.0.0.1 -t "pkru/iot/001/cmd" -v
mosquitto_pub -h 127.0.0.1 -t "pkru/iot/001/cmd" -m '{"led":"ON"}'

Topic Design

ข้อมูล:

pkru/iot/001/data

สถานะ:

pkru/iot/001/status

คำสั่ง:

pkru/iot/001/cmd

แบบฝึกหัด

ออกแบบ Topic สำหรับ 3 devices และ JSON ที่มี device_id, location, temperature, humidity, status, note
