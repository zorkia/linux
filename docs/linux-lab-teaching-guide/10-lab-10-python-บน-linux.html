วัตถุประสงค์

ติดตั้งและใช้งาน Python บน Debian Linux แบบเดียวกับ workflow ที่ใช้บน Raspberry Pi พร้อมเรียนรู้ Virtual Environment

เริ่มต้น

docker start -ai rpi-lab
su - piuser

1. ติดตั้ง Python

sudo apt update
sudo apt install -y python3 python3-pip python3-venv nano procps ca-certificates

ตรวจ:

python3 --version
pip3 --version

2. Python Interactive

python3

ทดลอง:

print("Hello Raspberry Pi")
2 + 3

ออก:

exit()

3. โปรแกรมแรก

mkdir -p ~/python-lab
cd ~/python-lab
nano hello.py

ใส่:

print("Hello from Python on Linux")

รัน:

python3 hello.py

4. Sensor Simulation

nano sensor.py
import random

temp = round(random.uniform(25, 40), 1)
humi = round(random.uniform(50, 90), 1)
light = random.randint(100, 3000)

print(f"temp={temp}")
print(f"humi={humi}")
print(f"light={light}")

รัน:

python3 sensor.py

5. Loop

nano sensor_loop.py
import random
import time

while True:
    temp = round(random.uniform(25, 40), 1)
    humi = round(random.uniform(50, 90), 1)
    light = random.randint(100, 3000)

    print(f"temp={temp}, humi={humi}, light={light}")
    time.sleep(2)

รัน:

python3 sensor_loop.py

หยุด:

Ctrl + C

6. JSON

nano sensor_json.py
import json
import random

data = {
    "temp": round(random.uniform(25, 40), 1),
    "humi": round(random.uniform(50, 90), 1),
    "light": random.randint(100, 3000),
}

print(json.dumps(data))

รัน:

python3 sensor_json.py

12. ข้อจำกัดของ Docker

Python/Linux application ทำงานใกล้เคียง Raspberry Pi มาก แต่ LAB นี้ไม่ได้จำลอง GPIO, I2C, SPI, BLE หรือ Wi-Fi hardware จริง

แบบฝึกหัด

สร้าง iot_device.py ที่:

  1. สุ่ม temp, humi, light
  2. สร้างข้อมูลแบบ JSON
  3. เพิ่ม device_id เป็น ESP32-001
  4. เพิ่มเวลาปัจจุบัน
  5. แสดงข้อมูลทุก 3 วินาที
  6. หยุดด้วย Ctrl+C

ตัวอย่างรูปแบบ:

{"device_id":"ESP32-001","temp":30.5,"humi":70.2,"light":1250}

คำถามท้าย LAB

  1. python3, pip และ venv ทำหน้าที่อะไร
  2. ทำไมควรใช้ Virtual Environment
  3. Ctrl+C ส่งผลอย่างไรต่อโปรแกรม Loop
  4. JSON เหมาะกับ IoT อย่างไร
  5. ส่วนใดของ Raspberry Pi ที่ Docker/Python Lab นี้ยังจำลองไม่ได้
