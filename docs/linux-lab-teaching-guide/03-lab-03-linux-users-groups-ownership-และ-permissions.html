LAB 03 - Linux Users, Groups, Ownership และ Permissions

ก่อนหน้า: LAB 02 - Linux Filesystem, Files, Directories และ Text Editorกลับหน้าแรกถัดไป: LAB 04 - Linux Package Management

ใช้ sudo และผู้ใช้ piuser ที่เตรียมใน LAB 01 ส่วน usermod, groupadd, getent, chmod และ chown มีอยู่ใน Debian Image ที่ใช้ ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

ฝึกจัดการผู้ใช้ กลุ่ม เจ้าของไฟล์ และสิทธิ์แบบเดียวกับที่ต้องใช้บน Raspberry Pi จริง

เริ่มต้น LAB

บน Windows:

docker start -ai rpi-lab

ภายใน Container:

su - piuser
whoami
id
groups

1. อ่าน Permission

cd ~
mkdir -p permission-lab
cd permission-lab
touch test.txt
ls -l test.txt

รูปแบบ:

-rw-r--r-- 1 piuser piuser ... test.txt
│└┬┘└┬┘└┬┘
│ │  │  └─ other
│ │  └──── group
│ └─────── owner
└───────── file type

r=read, w=write, x=execute

2. ตรวจสอบ User/Group

whoami
id
groups
getent passwd piuser
getent group sudo

3. chmod แบบ Symbolic

chmod u+x test.txt
ls -l test.txt
chmod g+w test.txt
chmod o-r test.txt
ls -l test.txt

4. chmod แบบ Numeric

r = 4
w = 2
x = 1

ทดลอง:

chmod 644 test.txt
ls -l test.txt
chmod 600 test.txt
ls -l test.txt
chmod 755 test.txt
ls -l test.txt

ความหมาย:

644 = rw-r--r--
600 = rw-------
755 = rwxr-xr-x

5. Ownership

สร้างไฟล์:

touch owner-test.txt
ls -l owner-test.txt

เปลี่ยนเจ้าของเป็น root:

sudo chown root:root owner-test.txt
ls -l owner-test.txt

คืนเจ้าของ:

sudo chown piuser:piuser owner-test.txt

6. สร้าง Group ทดลอง

sudo groupadd iot
sudo usermod -aG iot piuser
getent group iot
Group membership ใหม่จะมีผลเต็มที่หลังเริ่ม login session ใหม่

7. Permission กับ Directory

mkdir shared
chmod 700 shared
ls -ld shared
chmod 755 shared
ls -ld shared

8. Script และ Execute Permission

cat > hello.sh <<'EOF'
#!/bin/bash
echo "Hello Linux"
EOF
ls -l hello.sh
./hello.sh

ครั้งแรกอาจพบ Permission denied

แก้ด้วย:

chmod +x hello.sh
./hello.sh

แบบฝึกหัด

สร้าง:

~/permission-lab/iot/
├── config.txt
├── data.txt
└── run.sh

กำหนด:

  • config.txt = 600
  • data.txt = 644
  • run.sh = 755

ตรวจด้วย:

ls -l ~/permission-lab/iot

คำถามท้าย LAB

  1. owner, group และ other ต่างกันอย่างไร
  2. 644, 600, 755 หมายถึงอะไร
  3. chmod กับ chown ต่างกันอย่างไร
  4. ทำไม Shell Script ต้องมี Execute Permission
