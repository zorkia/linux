LAB 01 - เริ่มต้นใช้งาน Linux ด้วย Docker

ก่อนหน้า: Linux Lab Teaching Guide - Hubกลับหน้าแรกถัดไป: LAB 02 - Linux Filesystem, Files, Directories และ Text Editor
เครื่องมือสำหรับ LAB นี้

ติดตั้ง sudo, adduser, nano, iproute2 (ip) และ iputils-ping (ping) ตามขั้นตอนด้านล่าง หลังสร้างผู้ใช้แล้วสามารถ ติดตั้งเครื่องมือสำหรับทุก LAB ล่วงหน้า ได้

1. วัตถุประสงค์

LAB นี้ใช้ Docker เพื่อสร้างสภาพแวดล้อม Debian Linux สำหรับฝึกใช้งาน Linux ก่อนนำความรู้ไปใช้กับ Raspberry Pi จริง

เมื่อจบ LAB นักศึกษาจะสามารถ

  • เปิดและตรวจสอบ Docker Desktop
  • ดาวน์โหลด Debian Linux Image
  • สร้าง Linux Container
  • กำหนด Docker Port Mapping สำหรับ LAB ที่ต้องใช้ Web, Node-RED และ MQTT
  • เข้าใช้งาน Linux ผ่าน Terminal
  • เข้าใจความแตกต่างเบื้องต้นระหว่าง Docker Image และ Container
  • สร้างผู้ใช้ Linux
  • ใช้งาน sudo
  • ตรวจสอบ Network ของ Linux
  • ทดสอบการเชื่อมต่อ Internet และ DNS
  • ออกจากและกลับเข้า Container เดิมได้
LAB นี้เน้น Windows เป็นหลัก โดยใช้ Windows Terminal หรือ PowerShell เป็น host terminal เพื่อเข้าไปทำงานใน Debian Linux Container
ถ้าใช้ macOS ให้ใช้ Docker Desktop บน macOS และเปิด Terminal แทน PowerShell ได้ คำสั่ง docker ... ใช้บน host ส่วนคำสั่ง Linux เช่น apt, ip addr, sudo, /home/piuser ให้รันภายใน Container หลังจากเข้า rpi-lab แล้วเท่านั้น

Windows Notebook

          └── Mosquitto: 1883

Docker Container ใน LAB นี้ใช้สำหรับจำลองสภาพแวดล้อม Linux เท่านั้น ไม่ได้จำลอง Hardware ของ Raspberry Pi เช่น GPIO, I2C, SPI, Bluetooth และ Wi-Fi Interface จริง

ตั้งแต่ LAB 11 เป็นต้นไปจะมีบริการที่ต้องเปิดจาก Container ออกมายัง Windows/macOS host จึงกำหนด Port Mapping ตั้งแต่ตอนสร้าง Container:

Windows/macOS Host       Docker Container
localhost:8080     --->  80      Nginx
localhost:1880     --->  1880    Node-RED
localhost:1883     --->  1883    Mosquitto MQTT

ถ้าเครื่องอื่นอยู่ใน LAN เดียวกันและ Firewall อนุญาต สามารถเรียกผ่าน IP ของ Windows/macOS host ได้ เช่น http://IP-WINDOWS:8080

7. สร้าง Linux Container

docker run -it --name rpi-lab --hostname raspberrypi -p 8080:80 -p 1880:1880 -p 1883:1883 debian:trixie bash

ความหมาย:

  • docker run - สร้างและเริ่ม Container
  • -it - เปิด Terminal แบบ Interactive
  • --name rpi-lab - ตั้งชื่อ Container
  • --hostname raspberrypi - ตั้ง Hostname ภายใน Linux
  • -p 8080:80 - เปิด Web Server ใน Container port 80 ออกมาที่ host port 8080
  • -p 1880:1880 - เปิด Node-RED ออกมาที่ host port 1880
  • -p 1883:1883 - เปิด MQTT Broker ออกมาที่ host port 1883
  • debian:trixie - Image ที่ใช้
  • bash - เปิด Bash Shell

ถ้าพบข้อความว่า Container ชื่อ rpi-lab มีอยู่แล้ว ห้ามลบ Container เดิมทันที เพราะข้อมูลและโปรแกรมจาก LAB ก่อนหน้าอาจหาย ให้ตรวจสอบกับผู้สอนก่อนว่าจะใช้ Container เดิมต่อ, สำรองข้อมูล, หรือสร้าง Container ใหม่จาก Image สำรอง

เมื่อสำเร็จ Prompt จะเปลี่ยนเป็น

root@raspberrypi:/#

แสดงว่าขณะนี้กำลังใช้งาน Debian Linux ภายใน Docker Container

13.1 เตรียมเครื่องมือพื้นฐานสำหรับแล็บถัดไป

หลังทดสอบ sudo สำเร็จแล้ว ติดตั้งเครื่องมือสำหรับ LAB 02-09 ไว้ก่อน เพื่อให้คำสั่งพร้อมใช้ตั้งแต่เริ่มแล็บ:

sudo apt update
sudo apt install -y nano less tree file curl ca-certificates procps htop iproute2 iputils-ping dnsutils netcat-openbsd python3

procps เพิ่มคำสั่ง ps, top, pgrep, pkill, free และ uptime ที่ใช้ใน LAB 05 ส่วน python3 เตรียมไว้สำหรับตรวจตำแหน่งคำสั่งใน LAB 08 หากต้องการติดตั้งบริการและไลบรารีของ LAB 10-20 ล่วงหน้าด้วย ให้ใช้ หน้ารวมการติดตั้งเครื่องมือ

ขั้นตอนติดตั้ง nano, iproute2 และ iputils-ping ด้านล่างยังทำตามได้ แม้ติดตั้งจากคำสั่งรวมแล้ว

15. ติดตั้งเครื่องมือ Network

sudo apt install -y iproute2

ตรวจสอบ Network Interface

ip addr

ควรพบอย่างน้อย lo และ eth0

IP ของ eth0 เป็น IP ภายใน Docker Network ไม่ใช่ IP ของ Windows และไม่ใช่ Wi-Fi IP ของ Raspberry Pi จริง

จำไว้ว่า:

Container IP != Windows/macOS Host IP != Raspberry Pi IP จริง

ใน LAB นี้คำสั่ง Linux ส่วนใหญ่ทำงานภายใน Container ส่วนการเปิดหน้าเว็บจาก Browser บน Windows/macOS จะใช้ Port Mapping เช่น http://localhost:8080
