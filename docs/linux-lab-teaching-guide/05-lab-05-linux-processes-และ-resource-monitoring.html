LAB 05 - Linux Processes และ Resource Monitoring

ก่อนหน้า: LAB 04 - Linux Package Managementกลับหน้าแรกถัดไป: LAB 06 - Linux Networking
เครื่องมือสำหรับ LAB นี้

ps, top, pgrep, pkill, free และ uptime มาจากแพ็กเกจ procps ส่วน htop ต้องติดตั้งแพ็กเกจ htop ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

ฝึกตรวจสอบ Process, PID, CPU, Memory และการหยุด Process ซึ่งจำเป็นต่อการดูแล Raspberry Pi

เริ่มต้น

docker start -ai rpi-lab
su - piuser

เตรียมเครื่องมือก่อนตรวจ Process แม้จะติดตั้งไว้แล้วก็รันซ้ำได้:

sudo apt update
sudo apt install -y procps htop

1. Process

ps
ps aux

2. PID

echo $$

ค่าที่ได้คือ PID ของ Shell ปัจจุบัน

3. สร้าง Process ทดลอง

sleep 300 &

Shell จะแสดง Job/PID

ค้นหา:

ps aux | grep sleep
pgrep sleep

4. Background Job

jobs

สร้างอีกตัว:

sleep 500 &
jobs

5. หยุด Process

pgrep sleep

เลือก PID แล้ว:

kill PID

ตรวจ:

pgrep sleep

หยุด sleep ทั้งหมด:

pkill sleep

6. top

top

กด q เพื่อออก

7. htop

ถ้าติดตั้งจาก LAB 04:

htop

กด q เพื่อออก

8. Memory

free -h

9. Disk

df -h

10. Directory Usage

du -sh ~
du -sh ~/linux-lab

11. Uptime

uptime
ค่า uptime ใน Container ไม่ควรถูกตีความว่าเป็นเวลาเปิด Raspberry Pi จริง เพราะ Container แชร์ Kernel environment ของ Docker

แบบฝึกหัด

sleep 600 &
sleep 700 &
jobs
pgrep sleep
ps aux | grep sleep

จากนั้นหยุด Process ทั้งหมดโดยไม่ Restart Container

คำถามท้าย LAB

  1. Process คืออะไร
  2. PID คืออะไร
  3. ps, top, htop ต่างกันอย่างไร
  4. kill กับ pkill ต่างกันอย่างไร
  5. free -h และ df -h วัดคนละ Resource อย่างไร
