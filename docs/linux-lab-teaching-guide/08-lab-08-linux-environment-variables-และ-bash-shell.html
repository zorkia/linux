LAB 08 - Linux Environment Variables และ Bash Shell

ก่อนหน้า: LAB 07 - Linux Pipes, Redirects และ Text Processingกลับหน้าแรกถัดไป: LAB 09 - Bash Shell Script
เครื่องมือสำหรับ LAB นี้

ใช้ nano และ python3 สำหรับทดลองค้นหาคำสั่งด้วย which ส่วน Bash และ which มีอยู่ใน Image ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

เข้าใจ Shell, Environment Variables, PATH, command history, alias และ .bashrc

เริ่มต้น

docker start -ai rpi-lab
su - piuser
sudo apt update
sudo apt install -y nano python3

1. Shell

echo $SHELL

ตรวจ Bash:

bash --version

2. Environment Variables

env

ดูค่าบางตัว:

echo $HOME
echo $USER
echo $PATH

3. สร้าง Variable

device_id="ESP32-001"
echo $device_id

ตัวแปรนี้เป็น Shell Variable ใน session ปัจจุบัน

4. export

export MQTT_TOPIC="pkru/iot/001"
echo $MQTT_TOPIC

ทดสอบ Child Shell:

bash
echo $MQTT_TOPIC
exit

5. PATH

echo $PATH

ตรวจคำสั่ง:

which bash
which python3
which nano

6. History

history

แสดงบางส่วน:

history | tail

7. Alias

alias ll='ls -lah'
ll

Alias นี้หายเมื่อ session สิ้นสุดถ้าไม่บันทึก

8. .bashrc

เปิด:

nano ~/.bashrc

เพิ่มท้ายไฟล์:

alias ll='ls -lah'
export LAB_NAME="Raspberry Pi Linux Lab"

โหลดใหม่:

source ~/.bashrc

ทดสอบ:

ll
echo $LAB_NAME

9. Environment สำหรับ IoT

เพิ่มชั่วคราว:

export DEVICE_ID="001"
export MQTT_BROKER="test.mosquitto.org"
export MQTT_TOPIC="pkru/iot/$DEVICE_ID"

ตรวจ:

echo $DEVICE_ID
echo $MQTT_BROKER
echo $MQTT_TOPIC

10. unset

unset DEVICE_ID
echo $DEVICE_ID

แบบฝึกหัด

สร้างตัวแปร:

SITE=PKRU
DEVICE=ESP32-01
LOCATION=LAB

สร้าง TOPIC ให้ได้:

PKRU/ESP32-01/LAB

โดยประกอบค่าจากตัวแปร
