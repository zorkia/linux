LAB 13 - Mosquitto MQTT Broker

ก่อนหน้า: LAB 12 - SQLite Databaseกลับหน้าแรกถัดไป: LAB 14 - MQTT JSON and Topic Design
เครื่องมือสำหรับ LAB นี้

mosquitto เป็น Broker ส่วน mosquitto_pub และ mosquitto_sub มาจาก mosquitto-clients ใช้ nano, procps (ps) และ iproute2 (ss) เพื่อตั้งค่าและตรวจบริการด้วย ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

ติดตั้ง MQTT Broker และ Client Tools เพื่อจำลอง Raspberry Pi MQTT Server

LAB นี้ทดสอบ MQTT ภายใน Container ด้วย 127.0.0.1:1883 ก่อน ถ้าต้องการให้ Windows หรือเครื่องอื่นใน LAN เชื่อมต่อ Broker ผ่าน localhost:1883 หรือ IP-WINDOWS:1883 ต้องมีทั้ง Docker Port Mapping -p 1883:1883 และ Mosquitto listener ที่รับจาก network interface

ติดตั้ง

docker start -ai rpi-lab
su - piuser
sudo apt update
sudo apt install -y mosquitto mosquitto-clients nano procps iproute2

เปิด Listener สำหรับ LAB

สร้างไฟล์ config สำหรับ LAB:

sudo nano /etc/mosquitto/conf.d/lab-listener.conf

ใส่:

listener 1883 0.0.0.0
allow_anonymous true
การตั้งค่านี้เหมาะสำหรับ LAB ในเครือข่ายปิดเท่านั้น ยังไม่ใช่ configuration สำหรับ production

Start Broker

sudo mosquitto -c /etc/mosquitto/mosquitto.conf -d
ps aux | grep mosquitto
ss -tuln | grep 1883

Subscriber

เปิด Windows Terminal อีกหน้าต่าง:

docker exec -it rpi-lab bash

แล้ว:

su - piuser
mosquitto_sub -h 127.0.0.1 -t "lab/test"

Publisher

Terminal แรก:

mosquitto_pub -h 127.0.0.1 -t "lab/test" -m "Hello MQTT"

IoT Topics

Subscriber:

mosquitto_sub -h 127.0.0.1 -t "pkru/iot/#" -v

Publish:

mosquitto_pub -h 127.0.0.1 -t "pkru/iot/001/temp" -m "30.5"
mosquitto_pub -h 127.0.0.1 -t "pkru/iot/001/humi" -m "70.2"
mosquitto_pub -h 127.0.0.1 -t "pkru/iot/001/light" -m "1250"

MQTT กับระบบ Device Status Log

จาก LAB 12 เรามีเว็บฟอร์มที่บันทึกข้อมูลลง SQLite ด้วยมือ แต่ในงาน IoT จริง ข้อมูลส่วนใหญ่ควรมาจากอุปกรณ์ผ่าน MQTT

Payload ที่จะใช้ต่อใน LAB 15-16:

{
  "device_id": "ESP32-001",
  "location": "Lab Room",
  "temperature": 30.5,
  "humidity": 70.2,
  "status": "NORMAL",
  "note": "mqtt sensor"
}

ทดสอบ publish ข้อมูลรูปแบบเดียวกับเว็บ:

mosquitto_pub -h 127.0.0.1 \
  -t "pkru/iot/001/data" \
  -m '{"device_id":"ESP32-001","location":"Lab Room","temperature":30.5,"humidity":70.2,"status":"NORMAL","note":"mqtt sensor"}'

แนวคิดสำคัญคือ เว็บฟอร์มและ MQTT เป็นคนละทางเข้า แต่สุดท้ายสามารถบันทึกลง SQLite ตารางเดียวกันได้

ทดสอบจาก Windows หรือ LAN

ถ้า Container ถูกสร้างด้วย -p 1883:1883 แล้ว Windows สามารถใช้ MQTT client เชื่อมต่อได้ที่:

Broker: localhost
Port: 1883

เครื่องอื่นใน LAN ใช้:

Broker: IP-WINDOWS
Port: 1883

ถ้าเชื่อมต่อจากเครื่องอื่นไม่ได้ ให้ตรวจสอบ Windows Firewall ว่าอนุญาต port 1883 แล้วหรือยัง

Wildcard:

+ = หนึ่งระดับ
# = หลายระดับ

แบบฝึกหัด

ใช้ Topic pkru/iot/{student_id}/data แล้ว publish JSON ที่มี device_id, location, temperature, humidity, status, note จากนั้นใช้ Subscriber pkru/iot/+/data รับข้อมูลจากหลายอุปกรณ์
