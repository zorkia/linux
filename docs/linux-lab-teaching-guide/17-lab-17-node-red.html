LAB 17 - Node-RED

ก่อนหน้า: LAB 16 - Python MQTT Subscriber to SQLiteกลับหน้าแรกถัดไป: LAB 18 - Node-RED and MQTT
เครื่องมือสำหรับ LAB นี้

ติดตั้ง nodejs (node), npm และ node-red ผ่าน npm ใช้ procps (pgrep), iproute2 (ss) และ curl เพื่อตรวจบริการ ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

ติดตั้ง Node-RED และเรียนรู้ Flow-based IoT Programming

LAB 01 ควรสร้าง Container rpi-lab พร้อม -p 1880:1880 แล้ว เพื่อให้ Browser บน Windows/macOS เปิด Node-RED ได้ผ่าน http://localhost:1880

ถ้าใช้ Container เก่าที่ไม่ได้กำหนด -p 1880:1880 จะทดสอบ Node-RED ได้จากภายใน Container ด้วย curl เท่านั้น และ Browser บน Windows/macOS จะยังเข้าไม่ได้

ติดตั้ง

docker start -ai rpi-lab
su - piuser
sudo apt update
sudo apt install -y nodejs npm procps iproute2 curl ca-certificates
node --version
npm --version
sudo npm install -g --unsafe-perm node-red
node-red --version

Start

node-red

หยุดด้วย Ctrl+C

Run background:

nohup node-red > ~/node-red.log 2>&1 &
pgrep -af node-red
ss -tuln | grep 1880
tail ~/node-red.log
curl -I http://127.0.0.1:1880

เปิด Browser บน Windows/macOS:

http://localhost:1880

ถ้าเครื่องอื่นอยู่ใน LAN เดียวกันและ Firewall อนุญาต:

http://IP-WINDOWS:1880

แนวคิด Flow

Input → Processing → Output
Inject → Function → Debug

Docker กับ Pi จริง

ใน Docker Browser ต้องเข้า Node-RED ผ่าน Port Mapping ของ host เช่น http://localhost:1880

บน Raspberry Pi จริง Browser จะเข้า IP ของ Raspberry Pi โดยตรง เช่น http://192.168.1.20:1880

แบบฝึกหัด

พิสูจน์ว่า Node-RED ทำงานด้วย pgrep, ss, curl และเปิดหน้า http://localhost:1880 จาก Browser บน Windows/macOS
