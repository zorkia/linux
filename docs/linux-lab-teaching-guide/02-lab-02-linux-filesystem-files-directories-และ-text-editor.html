8. สำรวจโครงสร้าง Linux

จะพบ Directory สำคัญ เช่น

bin
boot
dev
etc
home
lib
media
mnt
opt
proc
root
run
srv
sys
tmp
usr
var

Directory ที่ควรรู้เบื้องต้น

Directory หน้าที่
/ จุดเริ่มต้นของ Filesystem
/home Home Directory ของ User
/etc Configuration ของระบบและโปรแกรม
/var ข้อมูลที่เปลี่ยนแปลง เช่น log และ web data
/tmp Temporary files
/usr Programs, libraries และข้อมูลที่ติดตั้งในระบบ
/proc ข้อมูลเกี่ยวกับ Kernel และ Process
/root Home Directory ของ root

28. ลบไฟล์

สร้างไฟล์ทดลอง

touch delete-me.txt

ตรวจสอบ

ls

ลบ

rm delete-me.txt

ตรวจสอบอีกครั้ง

ls
Linux ไม่มี Recycle Bin สำหรับคำสั่ง rm แบบปกติ ควรตรวจสอบชื่อไฟล์ก่อนลบเสมอ

29. ลบ Directory ว่าง

กลับไปที่

ตรวจสอบ

ls

ลบ Directory ว่าง

rmdir ลบได้เฉพาะ Directory ที่ไม่มีข้อมูล

30. ลบ Directory ที่มีข้อมูล

สร้างตัวอย่าง

mkdir test-delete
touch test-delete/file.txt

หากใช้

rmdir test-delete

จะไม่สามารถลบได้ เพราะ Directory มีข้อมูล

ลบ Directory พร้อมข้อมูลด้วย

rm -r test-delete
ใช้ rm -r ด้วยความระมัดระวัง เพราะเป็นการลบข้อมูลภายในทั้งหมด

42. คำถามท้าย LAB

  1. / และ ~ แตกต่างกันอย่างไร
  2. Absolute Path และ Relative Path แตกต่างกันอย่างไร
  3. . และ .. หมายถึงอะไร
  4. ls -la แตกต่างจาก ls อย่างไร
  5. mkdir -p มีประโยชน์อย่างไร
  6. cp และ mv แตกต่างกันอย่างไร
  7. > และ >> แตกต่างกันอย่างไร
  8. rm และ rmdir แตกต่างกันอย่างไร
  9. เพราะเหตุใดจึงต้องระมัดระวังการใช้ rm -r
  10. เมื่อ Stop Docker Container แล้วไฟล์ที่สร้างไว้หายหรือไม่
