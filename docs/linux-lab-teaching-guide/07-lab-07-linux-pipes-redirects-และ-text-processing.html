LAB 07 - Linux Pipes, Redirects และ Text Processing

ก่อนหน้า: LAB 06 - Linux Networkingกลับหน้าแรกถัดไป: LAB 08 - Linux Environment Variables และ Bash Shell
เครื่องมือสำหรับ LAB นี้

ps มาจากแพ็กเกจ procps และ less มาจากแพ็กเกจ less ส่วน grep, wc, sort, cut และ tee มีอยู่ใน Image ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

ฝึกแนวคิด Unix/Linux ที่นำ output ของคำสั่งไปเก็บ ค้นหา กรอง และต่อกับคำสั่งอื่น

เริ่มต้น

docker start -ai rpi-lab
su - piuser
sudo apt update
sudo apt install -y procps less
mkdir -p ~/text-lab
cd ~/text-lab

1. Standard Output

echo "Hello Linux"

2. Redirect >

echo "temp=30" > sensor.txt
cat sensor.txt

เขียนใหม่:

echo "temp=31" > sensor.txt
cat sensor.txt

สังเกตว่าข้อมูลเดิมถูกแทนที่

3. Append >>

echo "humi=70" >> sensor.txt
echo "light=1200" >> sensor.txt
cat sensor.txt

4. Pipe |

ps aux | less
cat sensor.txt | grep temp

5. grep

สร้าง:

cat > devices.txt <<'EOF'
ESP32-01 ONLINE
ESP32-02 OFFLINE
ESP32-03 ONLINE
ESP32-04 OFFLINE
ESP32-05 ONLINE
EOF

ค้นหา:

grep ONLINE devices.txt
grep OFFLINE devices.txt

ไม่สนตัวพิมพ์:

grep -i online devices.txt

6. wc

wc devices.txt
wc -l devices.txt
grep ONLINE devices.txt | wc -l

7. sort

sort devices.txt
sort -r devices.txt

8. cut

สร้าง CSV:

cat > sensors.csv <<'EOF'
device,temp,humi
ESP32-01,30.5,70
ESP32-02,31.2,68
ESP32-03,29.9,72
EOF

เลือก Column:

cut -d',' -f1 sensors.csv
cut -d',' -f2 sensors.csv

9. tee

echo "IoT Gateway" | tee gateway.txt
cat gateway.txt

เพิ่ม:

echo "MQTT Ready" | tee -a gateway.txt

10. Command Chain

ps aux | grep bash
cat devices.txt | grep ONLINE | wc -l
cut -d',' -f2 sensors.csv | tail -n +2

แบบฝึกหัด

สร้าง status.txt อย่างน้อย 10 บรรทัด มี ONLINE, OFFLINE, WARNING

ใช้คำสั่งเพื่อหาจำนวนแต่ละสถานะ โดยห้ามนับด้วยมือ

  2. Pipe | ทำอะไร
  3. grep ใช้ทำอะไร
  4. เพราะเหตุใด Pipe จึงสำคัญใน Linux
