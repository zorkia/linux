กลับหน้าแรกถัดไป: LAB 01 - เริ่มต้นใช้งาน Linux ด้วย Docker

คู่มือปฏิบัติการ Linux ผ่าน Docker สำหรับเตรียมความพร้อมก่อนใช้ Raspberry Pi

บริบทของชุด LAB

ชุดนี้ออกแบบให้นักศึกษาเรียนรู้ Linux โดยใช้ Docker Desktop สร้าง Debian Container ชื่อ rpi-lab ซึ่งมีสภาพแวดล้อมใกล้กับ Raspberry Pi OS มากพอสำหรับฝึก command line, package management, network, process, permissions และ IoT software stack

เครื่อง Windows หรือ macOS ทำหน้าที่เป็น host สำหรับเปิด Docker และ Terminal เท่านั้น หลังจากเข้า Container แล้ว ให้ถือว่าคำสั่งใน LAB ทำงานบน Linux

เตรียมเครื่องมือก่อนเรียน

ดู รวมคำสั่งและแพ็กเกจที่ต้องติดตั้งสำหรับ LAB 01-20 เพื่อเตรียมเครื่องมือ APT, Python venv และ Node-RED ล่วงหน้า หลังสร้าง Container และผู้ใช้ตาม LAB 01 แล้ว แต่ละ LAB จะระบุเครื่องมือที่ต้องใช้ย้ำอีกครั้ง

Raspberry Pi OS concepts

ใน Docker ต้องแยกให้ชัดว่า Container IP, Windows/macOS Host IP และ Raspberry Pi IP จริง เป็นคนละเรื่องกัน ถ้าต้องการให้ Browser หรือเครื่องอื่นใน LAN เข้า Web Server, Node-RED หรือ MQTT ภายใน Container ได้ ต้องสร้าง rpi-lab พร้อม Port Mapping ตั้งแต่ LAB 01

ชื่อที่ใช้ในเอกสาร

ค่า ความหมาย
rpi-lab ชื่อ Docker Container ที่ใช้ฝึก Linux
raspberrypi hostname ภายใน Container
piuser user ที่ใช้ฝึกเหมือนแนวคิด user บน Raspberry Pi
debian:trixie Docker image ที่ใช้เป็นฐานของ LAB
Windows Terminal / PowerShell host terminal สำหรับควบคุม Docker บน Windows
Terminal host terminal สำหรับควบคุม Docker บน macOS
