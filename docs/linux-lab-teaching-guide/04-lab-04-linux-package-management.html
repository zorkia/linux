LAB 04 - Linux Package Management

ก่อนหน้า: LAB 03 - Linux Users, Groups, Ownership และ Permissionsกลับหน้าแรกถัดไป: LAB 05 - Linux Processes และ Resource Monitoring
เครื่องมือสำหรับ LAB นี้

ฝึกติดตั้ง curl, htop, tree และติดตั้งแล้วถอน cowsay ถ้าเตรียมแพ็กเกจไว้แล้ว APT จะตรวจสอบเวอร์ชันให้ ยังทำตามแบบฝึกหัดได้ ดู รวมคำสั่งและการติดตั้งล่วงหน้า

วัตถุประสงค์

เข้าใจการติดตั้ง ค้นหา อัปเดต และลบ Software ด้วย APT ซึ่งใช้บน Debian และ Raspberry Pi OS

เริ่มต้น LAB

docker start -ai rpi-lab
su - piuser

1. ตรวจสอบ Repository

cat /etc/apt/sources.list

2. Update Package Index

sudo apt update
apt update อัปเดตรายการ Package ไม่ใช่การอัปเกรดโปรแกรมทั้งหมด

3. ดู Package ที่อัปเกรดได้

apt list --upgradable

4. ค้นหา Package

apt search curl
apt search htop

5. ดูรายละเอียด

apt show curl

6. ติดตั้ง Software

sudo apt install -y curl
sudo apt install -y htop

ตรวจสอบ:

curl --version
htop --version

7. ตรวจ Package

dpkg -l | grep curl
dpkg -l | grep htop

8. ตรวจตำแหน่ง Executable

which curl
which htop

9. ลบ Package

ติดตั้งตัวอย่าง:

sudo apt install -y cowsay

ค้นหา:

dpkg -l | grep cowsay

ลบ:

sudo apt remove -y cowsay

10. remove กับ purge

apt remove   ลบโปรแกรม แต่ configuration บางส่วนอาจเหลือ
apt purge    ลบโปรแกรมพร้อม configuration ที่ APT จัดการ

11. Autoremove

sudo apt autoremove

อ่านรายการก่อนยืนยันทุกครั้งในระบบจริง

แบบฝึกหัด

ให้นักศึกษา:

  1. apt update
  2. ค้นหา tree
  3. ดูรายละเอียด tree
  4. ติดตั้ง tree
  5. หา executable ด้วย which
  6. ตรวจด้วย dpkg -l

คำถามท้าย LAB

  1. apt update กับ apt install ต่างกันอย่างไร
  2. Repository คืออะไร
  3. apt remove กับ apt purge ต่างกันอย่างไร
  4. which ใช้ทำอะไร
